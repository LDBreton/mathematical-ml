Registro de verificación

Revisión actual del curso

Verificado localmente en Windows con Python 3.12.10 en el entorno del repositorio. Las versiones instaladas se registran en requirements-lock.txt; el manifiesto de galerías registra el entorno numérico de las salidas capturadas.

  • El curso contiene ahora ocho cuadernos guiados. Los ejercicios y soluciones separados están temporalmente retirados del árbol de fuentes, navegación y paquete descargable; sus versiones previas permanecen en Git. Cada lección amplía las explicaciones de opciones y ejemplos desarrollados. Los ocho cuadernos actuales se ejecutaron correctamente en núcleos separados y las capturas coinciden con todas las celdas fuente actuales.
  • Pasaron las 17 pruebas pytest, incluida la restauración de entorno y caché de la función auxiliar de API tras interrumpir una demostración.
  • Se exportaron 106 salidas reales en ocho galerías. Cada captura enlaza con su celda fuente. La construcción compara hashes SHA-256 normalizados del código y los datos para impedir capturas desactualizadas después de una edición.
  • Las 36 páginas HTML originales pasan las comprobaciones de enlaces locales, anclas, descargas y descripciones de imágenes. El código Python y de terminal se resalta durante la construcción con Pygments y una paleta Dark+ inspirada en VS Code.
  • Agrupamiento muestra el modelo elegido por silueta (k=2 en esta ejecución), tamaños de grupo, perfiles en unidades originales, mapa de calor de centroides estandarizados, proyección PCA y diagnóstico con diez inicios. La figura anterior con k=4 sigue identificada como ilustrativa.
  • Despliegue elige el umbral con validación, fija el pipeline ajustado, evalúa la prueba final una vez y guarda la política exacta. Las aserciones verifican igualdad de probabilidades antes y después de guardar y mediante la API, igualdad de umbral y decisión, y rechazo de entradas inválidas. MLflow registra el mismo artefacto sin reentrenar.
  • Clasificación incluye intervalos de fiabilidad y conteos de confusión. Eventos raros compara costo por umbral y volumen de alertas, con el costo de la política siempre negativa en la misma tabla. Texto muestra conteos dispersos, IDF, normalización, similitud coseno, familias y palabras desconocidas. Pronóstico comprueba que cambiar el objetivo contemporáneo y los futuros no altera sus predictores.

Registra en Git docs/results/ junto con los cambios correspondientes del material. Pages usa estas salidas versionadas; el flujo separado de verificación ejecuta todos los cuadernos desde cero. Las capturas documentan una ejecución local correcta. Los valores numéricos, inicializaciones y figuras pueden variar entre entornos compatibles.

Comprobaciones anteriores y limitaciones

Ya se probaron el entrenamiento por CLI, el seguimiento local con MLflow y los endpoints Uvicorn de salud y predicción. Los siete generadores CSV reprodujeron los archivos guardados en el entorno verificado. El repositorio y GitHub Pages son públicos, con despliegue automático al enviar a main; los flujos se ejecutaron correctamente.

Docker estaba detenido durante la verificación inicial, por lo que no se verificó construir ni ejecutar la imagen. Esta revisión usa un cliente HTTP dentro del proceso para el cuaderno de despliegue. MathJax necesita conexión; el resaltado de código y las figuras capturadas no requieren CDN. Los resultados sintéticos no establecen precisión real, calibración, causalidad ni preparación para producción.
