01 — Regresión: predicción de una respuesta numérica

La regresión predice un número. Estimaremos el precio de viviendas sintéticas a partir de medidas físicas y del vecindario. El objetivo es relacionar el criterio de predicción con un flujo de trabajo concreto en software, no explicar un mercado inmobiliario real.

Respuesta ruidosa ilustrativa y dos familias de funciones. Observa qué aspectos no puede capturar una recta; esta figura no muestra la evaluación del modelo de viviendas.

Cómo se relacionan los objetos de la biblioteca con las matemáticas

Una fila de X es un vector de entrada y la entrada correspondiente de y es la respuesta. Ridge(alpha=...) almacena la especificación de un modelo aún sin ajustar; fit(X, y) aprende los coeficientes y el intercepto. El guion bajo final de coef_ y intercept_ indica que se trata de estado aprendido. predict(X_new) evalúa la función ajustada en filas nuevas.

El preprocesamiento tiene una interfaz relacionada de dos pasos. fit aprende valores como la mediana, la media, la escala y el vocabulario de categorías a partir de las filas que recibe. transform aplica esos valores guardados sin aprender nada nuevo. Un Pipeline ejecuta estas operaciones en orden: al ajustar, primero ajusta el preprocesamiento y luego el estimador; al predecir, transforma los datos con el preprocesamiento ya ajustado y después predice. Por tanto, las filas reservadas usan transform o predict, nunca un nuevo fit.

ColumnTransformer aplica transformaciones distintas a las columnas numéricas y categóricas indicadas y luego concatena los resultados. OneHotEncoder representa las categorías mediante coordenadas indicadoras. GridSearchCV crea copias del pipeline y las ajusta para cada candidato y cada partición; así, el preprocesamiento se aprende solo con las filas de entrenamiento de esa partición. El nombre del parámetro model__alpha significa alpha configuración del paso del pipeline llamado model.

1. Predicción poblacional y mínimos cuadrados empíricos

Supongamos que $\mathbb E[Y^2]<\infty$. Para cualquier valor fijo de las características $X=x$, expandimos la pérdida cuadrática condicional alrededor de la media condicional:

$$\mathbb E[(Y-a)^2\mid X=x]=\mathbb E[(Y-\mu(x))^2\mid X=x]+(a-\mu(x))^2,$$

donde $\mu(x)=\mathbb E[Y\mid X=x]$. El término cruzado se anula porque $\mathbb E[Y-\mu(x)\mid X=x]=0$. Por tanto, el objetivo poblacional único bajo pérdida cuadrática es $f^*(x)=\mathbb E[Y\mid X=x]$ para casi todo $x$ respecto de $P_X$. La clase de modelos restringe qué funciones pueden aproximar esa media condicional, pero no cambia el objetivo.

Para una matriz de diseño $A\in\mathbb R^{n\times p}$, mínimos cuadrados ordinarios minimiza $\|y-A\beta\|_2^2$. Su gradiente es $-2A^T(y-A\beta)$, de modo que un minimizador satisface las ecuaciones normales $A^TA\hat\beta=A^Ty$. Geométricamente, $A\hat\beta$ es la proyección ortogonal de $y$ sobre el espacio columna de $A$. El rango completo de las columnas hace invertible $A^TA$ y único el vector de coeficientes. Si el rango es deficiente, los valores ajustados siguen siendo la proyección única, aunque varios vectores de coeficientes pueden alcanzarla.

4. Preprocesamiento y objetivo Ridge

Las columnas numéricas se estandarizan y neighborhood se codifica con indicadores one-hot. handle_unknown="ignore" evita errores en tiempo de ejecución ante una categoría futura ausente en el entrenamiento, representándola con ceros en todos sus indicadores. Esa categoría queda fuera del soporte de entrenamiento, por lo que la codificación no vuelve confiable la predicción. El preprocesamiento debe estar dentro del pipeline para que cada partición de validación cruzada aprenda medias, escalas, medianas y categorías solo con sus propias filas de ajuste.

Ridge resuelve $\min_{\beta_0,\beta}\sum_i(y_i-\beta_0-x_i^T\beta)^2+\alpha\|\beta\|_2^2$. Cuando $\alpha>0$, el sistema penalizado para las pendientes es definido positivo incluso si hay dependencia lineal entre predictores. En scikit-learn, el intercepto $\beta_0$ no se penaliza; para pendientes fijas, optimizarlo centra los residuos. Estandarizar las pendientes hace que una penalización común sea más comparable entre unidades numéricas. No añadas una columna constante de unos si el estimador ya ajusta su propio intercepto.

Python · ejecutar en el cuaderno
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.linear_model import Ridge
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import OneHotEncoder, StandardScaler

numeric_columns = ["area_m2", "bedrooms", "age_years", "distance_km"]
categorical_columns = ["neighborhood"]

numeric_preprocessing = Pipeline(
    steps=[
        ("impute", SimpleImputer(strategy="median")),
        ("scale", StandardScaler()),
    ]
)
categorical_preprocessing = Pipeline(
    steps=[
        ("impute", SimpleImputer(strategy="most_frequent")),
        ("one_hot", OneHotEncoder(handle_unknown="ignore")),
    ]
)
preprocessing = ColumnTransformer(
    transformers=[
        ("numeric", numeric_preprocessing, numeric_columns),
        ("category", categorical_preprocessing, categorical_columns),
    ]
)
regression_pipeline = Pipeline(
    steps=[("preprocessing", preprocessing), ("model", Ridge())]
)

Interpretar la configuración del pipeline a partir del objetivo

El código anterior compone imputación, escalado, codificación de categorías y ajuste por mínimos cuadrados penalizados. La tabla resume las opciones usadas en esta lección; los enlaces a la API documentan las interfaces completas.

Objeto o parámetro Valor usado Efecto y compromiso
SimpleImputer mediana para variables numéricas; valor más frecuente para las categóricas Aprende los reemplazos con las filas de ajuste. Conserva las filas incompletas, pero trata los valores imputados como valores ordinarios.
StandardScaler centrar y escalar las columnas numéricas Hace comparable la penalización de las pendientes entre unidades numéricas. Este pipeline no escala los indicadores one-hot.
OneHotEncoder handle_unknown="ignore" Crea un indicador por cada categoría observada en el entrenamiento. Una categoría nueva se representa con ceros y no recibe un efecto aprendido.
Ridge alpha valores candidatos [0.01, 0.1, 1, 10, 100]; fit_intercept=True Con la convención de scikit-learn, minimiza $\|y-b-Xw\|_2^2+\alpha\|w\|_2^2$. Un alpha mayor contrae más las pendientes; el intercepto no se penaliza.
KFold + GridSearchCV 5 particiones aleatorias; métrica RMSE; refit=True Compara alpha dentro de la partición de entrenamiento y vuelve a ajustar el ganador con todas las filas de entrenamiento disponibles. Se usa el RMSE negativo porque scikit-learn maximiza las puntuaciones.

Esto coincide con el objetivo de suma de cuadrados sin normalizar de la derivación. Si se expresa el término de ajuste como error cuadrático medio, el coeficiente de la penalización debe dividirse por el tamaño de la muestra para describir el mismo minimizador. El escalado y la codificación también determinan las coordenadas sobre las que actúa alpha. Consulta la documentación oficial de Ridge, Pipeline, y ColumnTransformer para ver las referencias.

# A fixed one-dimensional dataset isolates the effect of Ridge alpha.
# This illustrates shrinkage; no held-out score selects a setting.
small_X = np.array([[-2.0], [-1.0], [0.0], [1.0], [2.0]])
small_y = np.array([-3.0, -1.0, 0.2, 1.0, 4.0])
small_query = np.array([[-1.5], [0.0], [1.5]])
ridge_comparison = []
for alpha in (0.1, 1.0, 20.0):
    small_model = Ridge(alpha=alpha).fit(small_X, small_y)
    ridge_comparison.append({
        "alpha": alpha,
        "intercept": float(small_model.intercept_),
        "slope": float(small_model.coef_[0]),
        "training_SSE": float(np.sum((small_y - small_model.predict(small_X)) ** 2)),
        "predictions_at_-1.5_0_1.5": np.round(small_model.predict(small_query), 3).tolist(),
    })
pd.DataFrame(ridge_comparison)

5. Seleccionar la penalización solo con los datos de entrenamiento

Para cada alpha candidato, la validación cruzada de cinco particiones ajusta una copia nueva del pipeline completo con cuatro particiones y evalúa la quinta. scoring="neg_root_mean_squared_error" hace que las puntuaciones mayores sean mejores para la búsqueda; niega best_score_ para obtener el RMSE. refit=True vuelve a ajustar el pipeline ganador con todas las filas de entrenamiento. Las filas de prueba no intervienen en ninguna de estas operaciones.

Python · ejecutar en el cuaderno
from sklearn.model_selection import GridSearchCV, KFold

training_folds = KFold(n_splits=5, shuffle=True, random_state=27)
regularization_search = GridSearchCV(
    estimator=regression_pipeline,
    param_grid={"model__alpha": [0.01, 0.1, 1.0, 10.0, 100.0]},
    scoring="neg_root_mean_squared_error",
    cv=training_folds,
    refit=True,
)
regularization_search.fit(training_features, training_response)

selected_alpha = regularization_search.best_params_["model__alpha"]
training_cv_rmse = -regularization_search.best_score_
print(f"Selected Ridge alpha: {selected_alpha}")
print(f"Mean training-fold RMSE: {training_cv_rmse:,.0f} price units")

6. Una evaluación con datos reservados

MAE es el error absoluto medio en las unidades de la respuesta. RMSE penaliza más los errores grandes. $R^2$ compara con una predicción constante igual a la media del conjunto de prueba; puede ser negativo. Ninguna métrica por sí sola indica si el modelo sirve para una decisión concreta.

Python · ejecutar en el cuaderno
import numpy as np
import pandas as pd
from sklearn.dummy import DummyRegressor
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score


def summarize_regression_errors(actual_values, predicted_values):
    """Return three complementary regression metrics."""
    return {
        "MAE": mean_absolute_error(actual_values, predicted_values),
        "RMSE": mean_squared_error(actual_values, predicted_values) ** 0.5,
        "R²": r2_score(actual_values, predicted_values),
    }


best_regression_model = regularization_search.best_estimator_
test_price_predictions = best_regression_model.predict(test_features)

median_baseline = DummyRegressor(strategy="median")
baseline_training_input = np.zeros((len(training_response), 1))
baseline_test_input = np.zeros((len(test_response), 1))
median_baseline.fit(baseline_training_input, training_response)
baseline_predictions = median_baseline.predict(baseline_test_input)

mean_baseline = DummyRegressor(strategy="mean").fit(baseline_training_input, training_response)
mean_predictions = mean_baseline.predict(baseline_test_input)

test_metrics = pd.DataFrame(
    {
        "Ridge pipeline": summarize_regression_errors(test_response, test_price_predictions),
        "Training-mean baseline": summarize_regression_errors(test_response, mean_predictions),
        "Training-median baseline": summarize_regression_errors(
            test_response, baseline_predictions
        ),
    }
).T
test_metrics.round(2)

La media de entrenamiento es la constante óptima para la pérdida cuadrática de entrenamiento; la mediana de entrenamiento minimiza la pérdida absoluta. Compararlas relaciona las líneas base con sus objetivos. MAE es el error absoluto medio en unidades de precio. RMSE usa las mismas unidades, pero da más peso a errores grandes; para los mismos residuos, es al menos tan grande como MAE. La curvatura de los residuos puede señalar una relación no lineal ausente; un cambio en su dispersión puede indicar varianza no constante. Ninguna línea base debe usar las respuestas de prueba para elegir su constante.

7. Diagnóstico de residuos

Los residuos $e_i=y_i-\hat y_i$ pueden revelar curvatura, dispersión cambiante o subgrupos con errores sistemáticos. El gráfico invita a investigar; no demuestra que se cumplan los supuestos.

8. Interpretar los coeficientes con cautela

Para una variable numérica escalada, su coeficiente describe el cambio en la predicción ajustada por un aumento de una desviación estándar, condicionado a las demás entradas codificadas. El codificador conserva todos los indicadores de categoría, así que cada coeficiente categórico se expresa respecto del intercepto ajustado bajo la convención de penalización Ridge. Los contrastes entre pares de categorías son identificables en esta parametrización penalizada; los valores de cada categoría dependen de la penalización y la codificación. La correlación, la contracción y los factores omitidos afectan la interpretación. Son asociaciones condicionales del modelo, no efectos causales.

Conclusiones clave

  • Reserva los datos de prueba antes de seleccionar el modelo.
  • Mantén la imputación, el escalado y la codificación dentro del pipeline.
  • Compara con una línea base sencilla e informa errores en unidades interpretables.
  • Usa los gráficos de residuos para identificar dónde difieren los errores.
  • Las predicciones con datos sintéticos no demuestran precisión en el mundo real ni causalidad.
