# Adding a lecture

Keep notebooks runnable top-to-bottom with local data and no credentials. Use full sentences for assumptions and derivations, descriptive variable names, and one logical step per code block. Explain why each preprocessing and validation choice follows from the problem. Avoid test-set tuning and state which data are used for every choice.

Each lecture needs `README.md`, `lesson.ipynb`, `exercises.ipynb`, and `solutions.ipynb`. Include mathematical and implementation exercises, and make solutions self-contained. Leave notebook outputs clean. Add a dataset description with provenance, units, schema, and sampling assumptions. Update the course navigator's `LECTURES` list and root study route, then run pytest, the notebook runner, and the website builder.

No license is assigned automatically: the course owner should select a code/content license before public distribution. Synthetic fixtures were authored for this course and do not contain personal data.
